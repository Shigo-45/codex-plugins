Gemini Baton Settings

Configure writing fallback routes and optional sign-in. This page is served only on 127.0.0.1 for the current session and expires after inactivity. Settings are stored outside the repository.

Writing routes

Enabled routes run from top to bottom. Disabled routes stay available to re-enable. At least one route must stay enabled.

    API key

    GEMINI_API_KEY, GOOGLE_API_KEY, or GEMINI_BATON_ENV_FILE take precedence over a key saved here. A saved API key is stored in this machine's private external state and is never shown again.

    Account sign-in

    The sign-in buttons open the Gemini Web bridge login window. Complete sign-in there and close the window.

    Antigravity CLI

    This settings page does not send the saved API key to Google. Writing jobs send only their selected task material to Google.
